# Governance

CLI Gateway uses a maintainer-led, review-based model.

- Maintainers set release scope, security policy, and compatibility direction.
- Contributors propose changes through issues and pull requests.
- Security-sensitive and compatibility-breaking changes require maintainer
  approval and deny-path tests.
- Decisions should be recorded in issues, pull requests, or architecture
  documentation rather than private chat.
- A contributor may be invited as a maintainer after sustained, constructive
  work across implementation, review, documentation, and user support.
